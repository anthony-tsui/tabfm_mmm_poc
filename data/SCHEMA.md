# Dummy MMM CSV schema

**All values are synthetic/dummy.** They are not estimates of real marketing
performance and must not be used for business decisions.

## Primary file

`hk_skincare_mmm_dummy.csv` — generated by `scripts/generate_dummy_data.py`
with fixed seed `42`.

| Column | Type | Notes |
| --- | --- | --- |
| `time` | date (weekly) | `2024-01-01` … 12 weeks |
| `revenue` / `conversions` | KPI | Same synthetic revenue series (national) |
| `revenue_per_conversion` | float | Set to `1.0` for revenue KPI convenience |
| `baseline_revenue` | float | Planted non-media baseline |
| `incremental_revenue` | float | Sum of planted channel contributions |
| `*_spend` / `*_impression` | media | Per channel |
| `contribution_*` | ground truth | Planted media contribution for recovery metrics |
| `*_reach` / `*_frequency` | RF | YouTube & DV360 only |
| `*_control` | controls | Promo, competitor, sentiment |

## Channels

`google_sem`, `bing_sem`, `meta`, `youtube`, `dv360`, `ooh`

## Reference

`test_national_media_reference.csv` is an optional copy of the Meridian-style
national sample from
[meridian_mmm_data_pre_gen_poc](https://github.com/anthony-tsui/meridian_mmm_data_pre_gen_poc)
(`Channel0`…`Channel3`). It has no planted `contribution_*` columns; the
comparison defaults to the HK skincare dummy file.
